## Highlights

- **More than one monitor.** Each monitor gets its own bar, dock and notifications, and the launcher opens on the monitor you use. In Settings, drag the monitors to arrange them, choose the primary monitor, and set brightness, 10-bit colour and HDR for each monitor. CrownOS can also set the brightness of external monitors.
- **Set up your apps when you install.** The installer asks which browser and which developer tools you want. After the first start, CrownOS installs them in the background.
- **New apps in the App Store.** Google Chrome, Cursor, Claude Code and Codex.
- **A CrownOS boot screen.** The live image shows the CrownOS logo and a progress bar while it starts.
- **A better terminal.** fastfetch follows your theme, and CrownOS includes modern shell tools.
- **A new download location.** Download the ISO from https://download.crownos.org. SourceForge stays as a mirror.
