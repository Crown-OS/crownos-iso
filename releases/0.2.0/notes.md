# CrownOS 0.2.0

## Highlights

- **System updates from Settings.** Settings has a new System Updates page. It shows the next release and its notes, downloads it in the background, and installs it when you choose. CrownOS installs releases one after the other, so no release is skipped.
- **Roll back from the boot menu.** Before an update, CrownOS keeps a snapshot of the system and the current kernel. If the new release does not work for you, hold **Space** while the computer starts and choose *Rollback to CrownOS 0.2.0*.
- **rEFInd starts the system.** The boot menu stays hidden; it shows only while you hold a key at start.
- **The App Store is for apps.** It installs and updates apps. CrownOS releases come from Settings.
