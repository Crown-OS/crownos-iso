# crownos

The CrownOS desktop for Claude Code: skills that explain how to change system settings through the
RON files under `~/.config/crownos`, how to operate desktop apps and the browser through the
`crownos-computer-use` MCP server, how to use the visual context engine's memory, and how to write
themes and plugins; hooks that turn permission prompts, idle waits and finished turns into
crownotify cards; and the MCP server entry itself. Installed system-wide by the
`crownos-agent-skills` package and force-enabled through managed settings, so nothing needs
setting up. The MCP server starts once the crownos-computer-use component is installed.
